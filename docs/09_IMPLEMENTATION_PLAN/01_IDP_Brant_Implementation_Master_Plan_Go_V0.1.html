01

IMPLEMENTATION PLAN

计划原则

原则一

纵向切片，不先建空脚手架

每个切片都从命令、聚合、迁移、测试走到可重放的业务结果；目录随第一段真实代码创建。

原则二

以等价性降低风险

S1—S3 的退出条件是对应 Python 测试映射行全部有结论（通过、不适用或因 ADR 替代）。

原则三

阻断项前置

ADR-BR-004、ADR-BR-011 与十进制实现在 M0 用 PG16 实测后裁决，避免 S2、S3 返工。

原则四

证据回写档案

每个切片的测试、CI 与 PG16 证据像 Cargo V2.4—V2.9 那样回写到 06、10、12 阶段与版本登记。
