S2 EXECUTION REPORT

结论摘要

S2-04 · S2-08

核价计算规则

阶梯逐段计价、断档与重叠拒绝；MOQ 与订购倍数在按分组汇总后校验，不自动超采；同一费用义务只计一次，包含关系缺失或成环即拒绝；税额四种回收处理，部分回收按可回收率计算且不高于税率；汇率只用明确方向与 cost_estimate 用途；分摊以最小币值的最大余数法，合计严格等于总额。T02 §11 第 1—7 行与独立整数算术对照。

S2-01 · S2-02

SUP 供应条件

供应商询价引用 ready 询价行；供应报价、采购条件与物流报价各有草稿、修订、丢弃、核实或发布、撤回或退役；核实与发布须由草稿编辑人以外的人工执行；依附型采购条件随来源报价失效。核实检查与 CST 规则同码同序。

S2-06

SupplyConditionGuard v1 与 RfqGuard v1

下游事务内以 FOR SHARE 锁定确切修订行并判定是否仍有效；三种提交顺序实测符合设计。INQ 发布询价守卫，判定询价仍为 ready 且行集合未变。

S2-03

核价上下文与测量

实际核价须覆盖询价的完整行集合；假设使结果保持 provisional，不可冻结；测量记录与评估使用同一套测量规则。引用的来源须对操作者可读（R64）。

S2-05

场景评估与冻结

评估结果、规范化输入与全部绑定输入的内容哈希不可变地保存；冻结在同一事务内锁根、重新守卫依赖、重新评估并要求哈希逐字节一致，同一场景只冻结一次，并发冻结只有一个成功，Outbox 写入失败整体回滚。

S2-05 · S2-06

来源否认与 AdoptabilityGuard v1

来源否认是 CST 的事实：否认后依赖它的快照（含经锚点与来源报价的传递依赖）不再可采纳，新冻结被拒，历史可读；冻结与否认的竞争由数据库行锁裁决。可采纳守卫供 TRD、PUR 调用。
