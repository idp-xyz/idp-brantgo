<h2>Python V0.50 是 Go 实现的行为基准，而不是 Go 的验收证据</h2>

<p class="lede">IDP-Cargo 的 07、08 阶段审查的是它早期的 Python 参考实现（29＋60 项参考测试）。Brant 的 Python 实现规模大得多：{{=pythonSourceModules}} 个源模块、{{=pythonSourceLines}} 行，{{=pythonUniqueTests}} 个唯一测试方法，经 50 多个版本迭代。本审查说明它实现了什么、证明了什么、哪些结构不能照搬到 Go。</p>

::: cover
- 审查对象 | IDP_Brant_T04_A46采购准备_V0.50（brant_core＋t03_candidate；迁移第 17 版；本地 SQLite）
- 实测 | 2026-11-10 在 90 阶段 V0.50 ZIP 解压的副本上重跑全量 unittest：679 项通过（包内 uv.lock 环境，Python 3.12.13）
- 输出 | 模块清单、数据表对照、问题登记三份 CSV；重跑证据 JSON
:::

::: notice 证据边界
这里的“通过”只适用于 Python 参考实现与本地 SQLite。它不证明 Go 实现、PostgreSQL 16、真实身份、真实客户、模型调用或中国专业渠道。
:::

## 06 已实现规则的质量评价 {#s6}

:::cards
- 优点 | 证据纪律 | 每个增量都执行专项测试、联合回归、全量 unittest、候选契约检查、事务适配检查、Ruff、mypy 与 compileall，并在新鲜解压目录复验，命令输出与哈希随包保存。
- 优点 | 不可变事实 | 来源、商业修订、批准、确认、订单审批记录与采购草稿在数据库层禁止更新与删除，服务层同时守卫。
- 优点 | 错误语义 | 封闭错误结构、防泄露的 PERMISSION_DENIED／NOT_FOUND、存储故障不伪装为业务结果、拒绝审计独立记录。
- 优点 | 诚实边界 | 每份报告都写明“不代表什么”：合成资料、本地 SQLite、无真实身份、无渠道、非生产准入。
:::

这些规则是 Brant 最有价值的资产：报价审批时效、审核人当前资格、订单激活来源资格、销售汇率资格、成本范围映射等细则，都是在一轮轮“先复现缺口、再修复、再验证”的过程中固化下来的（例如 A26 先用四个失败测试复现成本来源否认后仍可激活的缺口）。Go 实现必须保持这些行为，不能只按规格重写而丢掉已经发现的边界情况。

## 08 未覆盖范围 {#s8}

- 没有 HTTP 服务与网页；execute-local 命令行只供持有本地数据库的开发者使用。
- 没有真实企业身份、岗位映射与团队细粒度访问控制；Principal 由受信任本地适配层构造。
- 没有 PDF／XLSX 解析、模型调用、EER 或 BIP 适配、真实邮件或渠道发送。
- 没有业务任务生命周期（Q01 旧包中的任务控制未进入 V0.50）。
- 没有采购承诺、质量、出运、结算、库存、生产协同、售后与中国专业协同。
- 没有 PostgreSQL、并发多进程、故障切主、容量与备份恢复验证。

## 09 结论与移植建议 {#s9}

1. **行为保留**：把 {{=pythonUniqueTests}} 个唯一测试方法逐项映射为 Go 等价用例（08 阶段），S1—S3 的退出条件是对应映射行全部有结论。
2. **结构重建**：不移植 t03_storage.py 的单体结构；按 TRD 的四个聚合与 PUR 的采购草稿拆分领域、应用与适配器包。
3. **并发重证**：SQLite 全库写串行掩盖了竞态；每个依赖串行化的守卫都要在 PG16 上用并发测试重新证明（ADR-BR-011）。
4. **一致性裁决**：同事务资格重查是 Python 正确性的前提，Go 中必须先裁决 ADR-BR-004。
5. **算术对照**：十进制实现（ADR-BR-REPO-10）以 T02、T03 的合成样例做独立算术对照，结果逐分一致。
6. **不保留绕过入口**：旧确认入口与早期订单激活入口的宽松语义只在迁移说明中记录，Go 不实现。
