MASTER WHITEPAPER

执行摘要

定位

一个系统贯通外贸经营

从询价、寻源、核价报价、订单，到采购及生产协同、质量、出运、结算与售后，Brant 维护业务事实与规则，AI 负责资料理解与受控任务协作。

边界

事实只有一个写入方

18 个候选限界上下文分别拥有主体、商品、商业政策、询价、供应条件、核价、报价与订单、采购、结算等事实；跨上下文只按引用与版本协作。

AI

意图到真实结果

首发必须有一条从意图到真实业务结果的 AI 主链（Q01）；AI 产生候选并走与人工相同的命令路径，人工核实、审批与正式化不可由 AI 代替。

证据

Python 证明规则可行

Python V0.50 用 50 多个迭代版本固化了报价、审批、客户确认、订单与采购草稿的规则，679 项测试在本机重跑通过；这些规则是 Go 实现的行为基准。

最重要的结论有三条：

  1. 范围不变，载体换成 Go。 产品范围、事实归属与验收组织沿用基线 V1.0；业务核心改为 Go 实现，Python V0.50 降为行为参考。
  2. 先裁决一致性策略，再写代码。 Brant 的设计要求报价正式化、订单激活与成本冻结在同一事务里重查上游事实；Cargo 的仓库基线与 idp-bento-go 的事务机制禁止跨上下文的事务内读取。这一冲突登记为 ADR-BR-004，是 G1 的阻断项。
  3. 以等价性推进迁移。 S1—S3 三个切片分别以 Python 的 T01＋共享基础、T02、T03＋T04 行为等价为退出条件；577 个唯一 Python 测试方法已映射到目标上下文，移植与通过分开登记。

产品定位与目标客户

Brant 面向中国境内 B2B 出口企业，管理从询价、寻源、核价报价、订单，到采购及生产协同、质量、出口履约、业务结算和经营分析的业务关系。首发以单一经营主体、自营一般贸易货物出口为基准，服装作为首个行业配置方向。

维度定义边界
目标客户中国 B2B 出口贸易企业（首发默认成品采购供给）完整自制制造、集团多主体、复杂代理与加工贸易不在默认首发范围
核心价值报价与订单承诺正确、可追溯；供应组织与履约受控；结算可解释不承诺未实测的人效、成交率或营收数字
AI 角色资料理解、方案组织、受控动作与结果核验不拥有交易事实，不自行批准，不扩大授权
专业办理资料准备、匹配、核实、差异与结果归档由 Brant 组织正式报关、开票、退税申报、银行与外汇办理由获准专业系统或授权人员完成
客户证据状态

基线要求进入真实试点前取得至少一笔普通出口与一笔变更或异常业务的脱敏资料。当前有合成样例 BRC-001 与模拟 G0 走查（04 阶段第 08 章：3 个虚构业务、6 项发现均已处置），但没有真实客户资料，因此 G0（客户场景确认）仍为 NO-GO。这不妨碍受控的 P0 研发，但阻断真实客户试点。

AI-Native 产品原则

产品基线已把 AI-Native 定为首发要求：首发必须交付至少一条从意图到真实业务结果的 AI 主业务链；只有资料识别、聊天问答或草稿补全不满足要求。AI 承担不确定的理解与组织工作，确定性规则由业务服务维护。

Q01

询价到可执行报价，再到授权订单

接收任务、识别需求、建立上下文、形成方案、审核报价、报价落地、等待回复、订单落地、核验结果九个阶段，每阶段有必须形成的证据。

目标

quote_ready 与 order_active

quote_ready 表示经审批的有效报价与正式文件已保存，不声称客户已收到；order_active 表示有足够客户确认依据且授权满足的订单已生效并通过核验。

任务

生命周期与控制权分开

BusinessTask 有 13 个生命周期状态；control_mode 为 ai 或 manual，control_epoch 单调递增；接管经 stopping 屏障，已提交事实不回滚。

核验

完成只看权威记录

completed 只能经目标断言核验进入；模型自述、客户端 completed=true 或中间草稿都不能代替。

原则规范性要求可证伪的验收
同一命令路径AI 与人工调用同一 Go 应用服务；聚合与数据库事务维护事实AI 不得直连仓储或数据库
人工专属命令主数据核实、询价范围核实、报价冻结与审批、正式化、客户接受核实、订单审批与变更、采购草稿编制与作废、放行只接受人工身份；完整清单以 05 阶段 humanOnlyCommands 为唯一来源AI 身份即使有通配授权也被拒绝
候选不是事实解析、匹配与分类结果是 AI 候选，经人工或确定性规则确认后才进入命令AI 分类的 full_unconditional 不能自证客户接受
执行三段回执ACCEPTED、COMMITTED、VERIFIED 分开错误宣称完成的用例必须失败
人工节点显式无渠道时人工发送或导入回复显示为人工节点并计入效率评测人工搬运不被统计为自动化
恢复不重复稳定 action_id、幂等命令与对账；提交后断连先读结果提交成功后进程宕机不重复创建业务结果

Brant 沿用 Cargo 的结论：AI 能力网关、委托策略、审批凭证、执行回执与评测放在 internal/ai，不是限界上下文。与 Cargo 不同的是，业务任务（BusinessTask）对人工与 AI 驱动都成立，作为 TSK 上下文登记（ADR-BR-003）。

确定性业务规则

以下规则是领域核心，不允许由 AI 或界面替代。Python V0.50 已实现其中多数，Go 与之保持等价；标注“有意背离”的条目按本档案 05 阶段执行，不移植 Python 的行为。

规则域规则来源
精度数量 6 位、单价 8 位、汇率 12 位、比例 8 位小数上限；计算至少 34 位有效数字；超限拒绝，不静默截断基线 4.1；T02 §3
舍入金额按币种最小单位 HALF_UP；行金额先舍入再求和；含税拆分以应付守恒T03 §5.1
汇率明确方向与用途（cost_estimate、quotation）；同币种明确 1；不默认、不反向、不交叉推导共享基础规格第 4 条
税价销售税须有独立的适用依据；购进成本口径不能冒充销售税；采购税额按核实口径全额、部分或不可回收，部分回收按经核实的可回收率计算；未知回收处理阻断T03 §5.1；T02 §13.3；CST-INV-007
毛利精确比较 R−C ≥ R×minimum_margin；低于阈值为 requires_approval，须独立的毛利例外批准，普通内容批准不覆盖（有意背离：Python 无例外通道）T03 §5.2；TRD-INV-007

Go DDD 总体架构

Brant 采用单仓库、单 Go Module 的模块化单体与六边形架构。18 个候选上下文是模型适用范围，不是部署单元；每个上下文在 Go 中是 internal/contexts/<bc>/{module.go, api/, internal/}，由编译器守住边界，由 Context Map 生成的 import 白名单约束依赖方向。

技术选择候选状态
语言与工具链Go 1.26.x 精确版本（与 idp-bento-go 一致；本机 go1.26.8）候选
框架go.idp.xyz/idp-bento-go v0.1.0-rc.2（Repository、Outbox、Inbox testkit）候选；本机模块缓存可用
数据库PostgreSQL 16；每个上下文一个 brant_<bc> schema；FORCE RLS候选
数据访问pgx/v5＋sqlc候选
接口net/http；OpenAPI 3.1；JSON Schema 2020-12候选
身份OIDC＋本地授权投影与 authority_epoch候选
事件Transactional Outbox／Inbox；事件来源 idp-brant.<bc>候选
金额整数最小单位＋精确有理数或经验证的十进制库；禁止 float64模拟评审接受：标准库 math/big（ADR-BR-REPO-10）
阻断项：跨上下文的事务内资格重查

Python 在单个 SQLite 事务（BEGIN IMMEDIATE 全库写串行）里重查成本快照、配置效力与审核人资格，保证“反证先提交则拒绝”。Go 基线要求每个上下文独立事务 owner，idp-bento-go 在另一个 owner 的事务中开事务会直接返回 transactionConflict，且默认隔离级别为 READ COMMITTED。三个候选方案与裁决要求见 03 阶段 ADR-BR-004 和 12 阶段第 9 章。严格的“反证先提交则拒绝”只对对外承诺之前的正式化与冻结必需；订单生效发生在合同成立之后，上游变化作为由订单审批确认的风险处理（ADR-BR-013）。

中国出口首发配置

默认首发配置为 CN-M01：境内单一经营主体、自营一般贸易货物出口。Brant 必须能组织获准出口业务的资料、匹配、差异、责任与外部结果；正式报关、开票、退税申报、银行与外汇操作由专业系统或授权人员执行，人工路径同样需要证据、版本、对账与成本记录。

控制规则设计约束（摘要）
CN-R02 单位与金额口径成交、库存、开票与法定单位分别保存；成交价、申报价与分析口径区分
CN-R03 税价分离可抵扣、可退与不可收回税额依实际政策核实；不得把全部采购税计成本又把预计退税计利润
CN-R05 外部状态本地草稿、导出、人工提交、外部受理、放行或核准、资金到账各自区分；unknown 先查证
CN-R07 报关变更海关放行、实际离境、物流送达与客户验收是不同事实
CN-R08 退税状态预计、拟申报、已提交、核准与到账分别记录
CN-R11 银行操作边界系统内核销只是商业资金分配，不得称为行政意义的出口收汇核销

中国配置的八项待决项（CN-D01—CN-D08：经营模式、税务办法、商品申报、票据、银行、专业系统、成本税额、单证期限）尚未冻结；在冻结之前，相关业务只允许保存草稿，不允许自动判定合规或完成专业办理。
